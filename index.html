// ABOUT

セキュリティ学習に、
年齢も経験も関係ない。

Team Howls（チームハウルズ）は、サイバーセキュリティを学びたいすべての人のための学習コミュニティです。

初心者がぶつかる「何から始めればいいか分からない」という最初の壁。 Team Howls は、その壁を一人で越えなくていい場所をつくります。 CTFへの挑戦、勉強会、情報共有、そして対等に議論できる仲間との出会い。学び続けるための環境を、コミュニティの力で用意します。

// FOUNDER MESSAGE
Koufu 代表 / Founder

「ひとりで学ぶ」を、
終わらせる。

Team Howlsをつくったのは、かつての自分と同じ孤独を、次の誰かに感じてほしくなかったからです。 「セキュリティを学びたい」という気持ちがあっても、独学には限界があります。 情報は溢れているのに、自分に合った順番で整理してくれる存在がいない。 そのまま何ヶ月も動けずにいた経験が、このコミュニティの出発点にあります。

だからこそ、Team Howlsはただ成長するためだけの場所ではありません。 互いの視点から新しい世界を知り、疑問を持ったときには相談し、教え合いながら、 ともに学び続けられる場所でありたいと考えています。 コミュニティの存在は、一人きりだった学びを飛躍的に加速させます。

いつから始めようかなどと考えているときには、すでに遅れを取っている
――クインティリアヌス (35-100年頃, ローマ帝国の修辞学者)

セキュリティは、インターネットとともに生きるすべての人にとって重要な分野です。 何歳でも、未経験でも、"今"ここから、私たちと一緒に一歩を踏み出してみませんか？

// FEATURES

Team Howls を支える、
3つの仕組み。

SIGNAL / 01

Discord内での交流・学習

個人チャンネル、timesやサーバー、ボイスチャットを通じた仲間たちと共に学ぶ環境を提供します。

SIGNAL / 02

メンバー主導の独自イベント

他にはないTeamHowls独自の視点から、セキュリティを楽しく学べるイベントを開催。

SIGNAL / 03

メンターによる伴走型サポート

経験豊富な運営メンバーが1対1の相談や質問に対応します。学習の進め方や方向性をアドバイスし、「挫折させない」環境をサポートします。
