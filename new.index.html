// ABOUT

セキュリティ学習に、
年齢も経験も関係ない。

Team Howls（チームハウルズ）は、サイバーセキュリティを学びたいすべての人のための学習コミュニティです。

初心者がぶつかる「何から始めればいいか分からない」という最初の壁。 Team Howls は、その壁を一人で越えなくていい場所をつくります。 CTFへの挑戦、勉強会、情報共有、そして対等に議論できる仲間との出会い。学び続けるための環境を、コミュニティの力で用意します。

// FOUNDER MESSAGE
Koufu 代表 / Founder

セキュリティを、
もっと身近に。

Team Howlsをつくったのは、かつての自分と同じ場所で立ち止まっているひとの存在が頭から離れなかったからです。「セキュリティを学びたい」という気持ちがあっても、どこから手をつければいいかわからない。そのまま何ヶ月も動けずにいた経験が、このコミュニティの出発点にあります。

独学には限界があります。情報は溢れているのに、自分に合った順番で整理してくれる存在がいない。間違えたときに「それは違う」と優しく教えてくれる仲間がいない。私が感じた孤独を、次の誰かには感じさせたくないと思いました。

Team Howlsは、上手くなることだけを目標にしていません。学び続けられることを大切にしています。挫折しそうになったとき、声をかけてくれる仲間がいること。疑問を持ったとき、すぐに相談できる場所があること。それだけで、人はずっと先まで進んでいける。

セキュリティはこの時代を生きるすべての人に関係する学問です。難しそう、自分には無理、そんなことは一切ありません。あなたの好奇心は、ここで必ず仲間になれます。一緒に遠くへ行きましょう。

// FEATURES

Team Howls を支える、
3つの仕組み。

SIGNAL / 01

Discord内での交流・学習

個人チャンネル、timesやサーバー、ボイスチャットを通じた仲間たちと共に学ぶ環境を提供します。

SIGNAL / 02

メンバー主導の独自イベント

他にはないTeamHowls独自の視点から、セキュリティを楽しく学べるイベントを開催。

SIGNAL / 03

メンターによる伴走型サポート

経験豊富な運営メンバーが1対1の相談や質問に対応します。学習の進め方や方向性をアドバイスし、「挫折させない」環境をサポートします。
